# Pawzeeble — asset pack

Every image, icon and brand file used in `Pawzeeble Website v2.dc.html`.

## brand/  (fixed — do not swap)
- `pawzeeble-logo.png` — main logo (header, footer)
- `pawteckt-logo.png` — Pawteckt plan logo
- `pzb-coin.png` — PZB coin (rewards)
- `tostb-black.webp` — partner mark

## badges/  (fixed)

- `badge-instant-booking.png` — all clinics
- `badge-app-store.png`, `badge-google-play.png` — store buttons / booking popup

## icons/
- `play-circle.svg` — podcast play button (fill orange `#F26B1D` / brand orange)
- `001…106-*.svg` — every inline icon from the site, numbered in order of appearance; name = nearest label. Open `icons/_index.html` to browse.
- Stroke icons use `currentColor` — set CSS `color` to recolour. Selected states use violet `#6351A1`.
